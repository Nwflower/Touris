# 杭州、广州 2—7 日攻略


整理于2026-09-12。下面为本项目按片区和主题编排的路线，不是官方原文转载。每套路线取前 N 天即为 N 日版；从2天到7天每天都有具体点位，单条行程不重复景点。游览次序不是导航路径，入馆、登塔和跨片区交通请另行核对。


## 杭州

### 湖城经典型
湖景、古寺与运河，逐天拓展片区

- 第1天：西湖 → 雷峰塔 → 清河坊

- 第2天：灵隐寺 → 杭州植物园

- 第3天：浙江省博物馆（孤山馆区） → 保俶塔

- 第4天：拱宸桥 → 香积寺

- 第5天：良渚博物院

- 第6天：中国茶叶博物馆（双峰馆区） → 龙井村

- 第7天：中国丝绸博物馆 → 六和塔

### 文博古建型
从城市历史走到茶与丝绸文化

- 第1天：杭州博物馆 → 清河坊

- 第2天：浙江省博物馆（孤山馆区） → 保俶塔

- 第3天：中国茶叶博物馆（双峰馆区） → 中国丝绸博物馆

- 第4天：拱宸桥 → 香积寺

- 第5天：良渚博物院

- 第6天：净慈寺 → 雷峰塔

- 第7天：杭州大剧院 → 西湖

### 自然茶乡型
园林、湿地与茶乡，每天留足慢逛时间

- 第1天：杭州植物园 → 保俶塔

- 第2天：西溪湿地

- 第3天：龙井村 → 中国茶叶博物馆（双峰馆区）

- 第4天：西湖 → 净慈寺

- 第5天：六和塔 → 中国丝绸博物馆

- 第6天：灵隐寺

- 第7天：拱宸桥 → 香积寺


2日版用于周末初访，3—4日版增加主题片区，5—7日版加入远端或深度点位；长线可能包含相同城市地标，三套方案通过顺序、主题及密度形成差异。


## 广州

### 羊城经典型
老西关、城市地标与历史文化

- 第1天：陈家祠 → 永庆坊 → 沙面

- 第2天：广东省博物馆 → 广州塔

- 第3天：越秀公园 → 中山纪念堂 → 南越王博物院（王墓展区）

- 第4天：北京路步行街 → 石室圣心大教堂

- 第5天：白云山

- 第6天：华南国家植物园

- 第7天：宝墨园

### 古建文博型
寺院古建、考古与当代艺术

- 第1天：光孝寺 → 六榕寺

- 第2天：南越王博物院（王墓展区） → 中山纪念堂

- 第3天：陈家祠 → 永庆坊

- 第4天：广东省博物馆 → 广州图书馆 → 广州大剧院

- 第5天：黄埔军校旧址纪念馆

- 第6天：广州艺术博物院（新馆） → 广州塔

- 第7天：北京路步行街 → 石室圣心大教堂

### 山水休闲型
山林、公园与水岸，放慢游览节奏

- 第1天：白云山

- 第2天：荔湾湖公园 → 沙面

- 第3天：华南国家植物园

- 第4天：越秀公园 → 广州动物园

- 第5天：宝墨园

- 第6天：广州塔 → 广州大剧院

- 第7天：永庆坊 → 北京路步行街


2日版用于周末初访，3—4日版增加主题片区，5—7日版加入远端或深度点位；长线可能包含相同城市地标，三套方案通过顺序、主题及密度形成差异。
